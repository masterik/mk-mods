# vscode

VS Code's default 2026 colors for the Claude desktop and mobile apps: **Light 2026** in light mode,
**Dark 2026** in dark mode. Accent is VS Code's blue; errors red, warnings amber, git
added/removed/modified as the 2026 themes' git decorations. Code blocks use GitHub Light / Dark, which
the 2026 token colors are built on.

The conversation sits on the editor color (white, `#121314`), with the person's messages in the chat
request bubble's tint; side bar, panels and menus step up as in VS Code.

## Install

```
/plugin marketplace add masterik/mk-toolkit
/plugin install vscode@masterik
```

The terminal draws no theme.

Colors: [microsoft/vscode](https://github.com/microsoft/vscode/tree/main/extensions/theme-defaults/themes)
`2026-light.json` / `2026-dark.json` (MIT).
